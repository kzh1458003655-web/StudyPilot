# 前端模拟服务

运行 `corepack pnpm run dev:mock` 后，浏览器中的 Service Worker 会接管现有的
`/api/v1` 请求。页面、请求模块和响应结构仍使用真实后端契约；普通的
`corepack pnpm run dev` 不启用模拟服务，仍连接真实后端。

模拟数据按课程项目集中存放在 `fixtures.ts`，每个项目独立拥有资料、问答、考频、
试卷和测评数据：

| 项目          | 主要检查场景                       |
| ------------- | ---------------------------------- |
| 01 空白项目   | 所有模块初始空状态                 |
| 02 资料处理中 | 等待、处理中、导入失败、较慢响应   |
| 03 问答进行中 | 多轮问答、多引用、证据不足         |
| 04 考频已分析 | 多年份真题、待处理真题、长考频列表 |
| 05 已生成试卷 | 多套试卷、长标题、选择与简答题     |
| 06 已完成测评 | 满分、零分、部分得分和长反馈       |
| 07 边界与异常 | 超长文本、模块接口错误、窄屏溢出   |
| 08 已归档     | 归档项目及其完整历史记录           |

新建课程、上传/删除资料、问答、生成/删除试卷、答题和归档操作会写入浏览器
`localStorage`，刷新页面后仍保留，且不会写入真实数据库。需要恢复初始场景时，在
浏览器控制台执行：

```js
localStorage.removeItem("studypilot.mock.database.v1");
location.reload();
```
