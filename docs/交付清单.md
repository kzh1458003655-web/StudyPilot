# StudyPilot 最终交付清单

本清单面向组员、答辩演示和后续维护，说明仓库中交付了什么、怎样复现，以及证据保存在哪里。

## 1. 已交付内容

| 类别 | 交付物 | 用途 |
| --- | --- | --- |
| 前端 | `frontend/` | Vue 页面：创建项目、资料管理、知识问答、真题分析、模拟卷、在线作答与评分结果。 |
| Java 后端 | `backend/` | Spring Boot REST 接口、业务工作流、JDBC Repository、PDF 处理和 PostgreSQL Schema。 |
| C++ 服务 | `ai/` | 文档索引、检索、模型请求转发、推理队列和健康检查。 |
| 数据库 | `backend/src/main/resources/db/schema/` | 七份按固定顺序执行的 PostgreSQL DDL。 |
| 启动脚本 | `scripts/start-target.ps1`、`stop-target.ps1` | 在已准备依赖的电脑启动或停止目标架构。 |
| 验证脚本 | `scripts/verify-target.ps1` | 运行后端、前端、Harness、模拟卷 HTTP 工作流；`-RunBrowser` 额外运行 Chromium 场景。 |
| 文档 | `README.md`、`docs/` | 架构、数据库、接口、部署、模型评测、验证与交接说明。 |

## 2. 从克隆到运行

1. 克隆仓库，安装 Java 21、Node.js/pnpm、PostgreSQL 客户端、C++ 编译工具链和 llama.cpp。
2. 在 `frontend` 执行 `pnpm install`，在 `ai` 执行 `build.cmd`。
3. 创建 PostgreSQL 数据库，在当前 PowerShell 会话设置 `STUDYPILOT_DB_URL`、`STUDYPILOT_DB_USERNAME`、`STUDYPILOT_DB_PASSWORD`。
4. 执行 `backend/scripts/verify-schema.ps1` 初始化数据库。
5. 使用 GGUF 模型启动 llama.cpp 18082，再执行 `scripts/start-target.ps1 -StartAiService`。
6. 在浏览器打开 `http://127.0.0.1:5173`。

完整命令、变量含义、端口和停止方式见 [部署与运行指南](部署与运行指南.md)。

## 3. 答辩演示顺序

1. 创建“操作系统期末复习”项目，说明项目 ID 是数据隔离边界。
2. 上传一份教材或讲义 PDF 和一份历年真题 PDF，查看资料状态。
3. 在知识问答页提问，展示回答的资料名称、页码和原文引用。
4. 在真题分析页填写真题资料编号，展示知识点频次。
5. 生成模拟卷，说明固定生成 2 道单选题和 2 道简答题，模型输出会经过程序校验。
6. 进入在线作答，分别填写单选和简答，提交后展示总分与逐题反馈。
7. 说明数据库记录的错题、掌握度和建议如何由本次作答产生。
8. 打开 `GET /api/v1/health/dependencies` 或 C++ `/health`，展示本地模型、队列和检索服务状态。
