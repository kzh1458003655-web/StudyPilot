# 课程资料与知识问答模块实现说明

## 1. 已实现功能

用户创建课程后，在知识问答页面右侧上传文字型 PDF。页面同时提供资料列表、处理状态和删除入口，不再设置独立的“资料库”页面。

后端计算文件 SHA-256，使用 PDFBox 按页提取文字并分块，然后调用 C++ 服务建立检索索引。只有文件、分页内容、文本块和索引均处理完成后，资料状态才变为 `READY`。

问答优先检索当前课程中的教材、讲义和知识点资料。Java 对 C++ 返回结果再次执行索引 ID 白名单过滤，引用中的资料名称、页码和原文摘录来自服务端快照，不使用模型自行生成的来源。

没有上传资料或检索不到相关片段时，系统仍调用本地模型按通用知识回答，但引用列表保持为空。问答结果不会显示“未引用资料”等多余提示。

## 2. 数据流

```text
Vue 知识问答页
  ├─ 上传 PDF → Java 保存文件、提取文字和分块 → C++ 建立索引
  ├─ 提交问题 → Java 选择当前课程资料 → C++ 检索 → 本地模型回答
  └─ 删除资料 → Java 删除数据库记录和文件 → C++ 删除索引

PostgreSQL
  ├─ projects / documents / document_pages / document_chunks
  └─ qa_sessions / qa_messages / qa_retrieval_records / qa_citations
```

问答历史按课程保存。页面重新进入或刷新时读取最近一次会话；资料删除后，已经保存的引用快照仍可用于查看历史回答。

## 3. 当前交互

- 左侧课程列表用于创建、切换、归档和恢复课程；
- 中间区域显示问答历史和输入框；
- 右侧区域上传、列出和删除当前课程资料；
- 有资料时显示“优先使用当前课程资料”；
- 没有资料时显示“当前无资料，将使用本地模型回答”；
- 正在执行的问答任务存放在全局状态中，切换模块不会主动中止请求。

## 4. 接口

| 方法 | 地址 | 作用 |
| --- | --- | --- |
| `POST` | `/api/v1/projects` | 创建课程 |
| `GET` | `/api/v1/projects` | 查询课程列表 |
| `POST` | `/api/v1/documents` | 上传 PDF，表单包含 `projectId` 和 `file` |
| `GET` | `/api/v1/documents?projectId=...` | 查询当前课程资料 |
| `DELETE` | `/api/v1/documents/{id}?projectId=...` | 删除资料、文件和索引 |
| `POST` | `/api/v1/qa` | 提问，包含 `projectId`、`question` 和可选 `sessionId` |
| `GET` | `/api/v1/qa/history?projectId=...` | 恢复当前课程问答历史 |

## 5. 项目隔离和异常处理

资料查询、检索范围、问答会话和引用都带有 `projectId`。即使手工修改会话或资料编号，后端也会验证其课程归属。

当前只支持不超过 25 MB、带有文字层的 PDF。模型、检索服务或数据库不可用时，接口返回明确的失败信息；系统不会把未完成索引的资料标记为可用。

## 6. 验证重点

- PDF 上传、分页、分块、索引建立和删除；
- 同一课程资料命中和引用页码；
- 无资料与无检索命中时的通用知识回答；
- 问答历史在刷新和模块切换后的恢复；
- 不同课程的资料、会话和引用隔离；
- C++ 或模型不可用时的错误返回。

真实资料问答链路可以通过 `GroundedQaEndToEndTest` 验证。常规后端测试使用 `backend/mvnw.cmd test`，前端检查使用 `pnpm run check`。
