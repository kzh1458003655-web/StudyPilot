# 在线作答与智能测评模块实现说明

## 业务流程

用户在模拟卷预览页点击“开始在线作答”，系统为本次作答建立独立 `exam_attempts` 记录。即使同一份试卷被反复练习，每一次答案、得分和诊断都不会覆盖此前记录。

提交时必须覆盖试卷中的全部题目：

- 单选题由服务端将选项编号与标准答案比较，结果为规则评分；
- 简答题将参考答案与学生答案发送到本地模型，模型只允许返回 `score` 和 `feedback` 的 JSON；分数范围和反馈内容会在入库前校验；
- 每道题保存答案、得分、反馈、评分方式和评分依据；
- 得分低于题目满分 60% 时写入错题与复习建议；每次得分比例参与项目知识点掌握度的累计平均值。

所有读取和写入经由模拟卷所属项目校验。错误项目、已提交的作答记录或不完整提交都会被拒绝。

## 主要接口

| 方法 | 地址 | 作用 |
| --- | --- | --- |
| POST | `/api/v1/assessments/attempts?projectId=&examId=` | 创建一次独立作答 |
| POST | `/api/v1/assessments/attempts/{attemptId}/submit?projectId=` | 提交全部答案并返回测评报告 |

页面地址是 `/projects/:projectId/assessment?examId=:examId`，由模拟卷预览页进入，逐题填写而不要求用户手写 JSON。

## 数据表关系

```text
mock_exams → exam_attempts → attempt_answers → grading_details
                                      └──────→ wrong_questions
项目知识点得分 ───────────────────────────────→ mastery_records
错题触发建议 ───────────────────────────────→ recommendation_records
```

`attempt_answers` 使用 `(attempt_id, item_id)` 唯一约束防止同一尝试重复写题。删除项目时，所有测评数据依赖外键自动清理。

## 验证

```powershell
cd backend
./mvnw.cmd -Dtest=AssessmentServiceTest,PostgreSqlSchemaIntegrationTest test
./mvnw.cmd -Dstudypilot.e2e=true -Dtest=MockExamWorkflowEndToEndTest test

cd ../frontend
pnpm run check
```

第一条命令验证规则评分、模型评分结果校验、错题/掌握度/建议写入和真实 PostgreSQL 表约束；第二条命令完成创建项目、导入、组卷、开始作答、提交和评分的完整 HTTP 工作流。端到端中的外部模型、检索和索引网关使用受控实现，以使结构化输出稳定复现；资料问答模块的端到端测试仍覆盖实际 C++ 与本地模型服务。
