# 重构复用清单

本文件记录旧课程版实现中可复用的行为、测试和纯逻辑。所有条目都必须在 `ARCH-001` 中重新检查；“候选”不代表允许直接复制到目标架构。

## 复用规则

1. 先建立旧行为的测试或输入输出证据。
2. 只复用符合目标模块职责的逻辑。
3. 不带入旧包结构、MySQL 方言、本机路径或跨层耦合。
4. 在目标模块中重新命名和组织，使其符合新架构。
5. 通过新旧行为对照后才能标记“已复用”。
