# ADR-003：通过独立工作树保留并选择性复用旧代码

- 状态：已接受
- 日期：2026-09-08

## 背景

旧课程版实现包含已验证行为和测试，完全忽略会增加重写成本；把旧代码长期放在当前目标目录中又会混淆架构边界。

## 决定

- `ARCH-001` 创建 `archive/legacy-course-prototype` 分支。
- 旧实现通过当前仓库之外的 Git worktree 查看。
- 当前目标工作目录不保留 `legacy/` 副本。
- 优先复用测试、纯算法、业务约束和已验证行为。
- 不整目录复制旧包、旧配置或旧 SQL。
- 每项复用写入 `重构复用清单.md`，并提供行为对照证据。

## 备选方案

- 当前仓库保留 `legacy/`：目录直观，但容易被 Agent 当成目标代码继续修改。
- 只依赖 Git 历史：目录最干净，但频繁对照和运行旧版本不方便。
- 完全从零实现：减少旧耦合，也会丢失已有测试和经验。

## 影响

- 目标目录保持清晰。
- 创建外部 worktree 前必须验证绝对路径和分支，避免影响当前工作区。
- 复用需要额外的特征测试和映射记录。

## 验证和回退

- `ARCH-001` 验证归档分支可检出、外部 worktree 可运行、当前目录无旧副本。
- 若某项复用造成架构污染，回退该目标提交并把条目标记为“仅参考”。
