# 接口与数据契约索引

本文件是跨层接口的索引，不复制每个模块的完整 DTO。具体契约在相应架构或模块文档中定义，并由实现和契约测试验证。

## 当前状态

当前运行分支已完成资料问答、真题分析与模拟卷、在线作答与测评接口。课程版接口只保留在归档分支中作为行为参考；当前目标接口、数据库字段和 C++ 协议均有实现与测试。

## 目标后端接口

目标约定来自 [后端框架设计](../../backend/docs/后端框架设计.md)：

```text
/api/v1/health
/api/v1/documents
/api/v1/qa
/api/v1/exams
/api/v1/assessments
```

- 普通响应使用统一数据和请求 ID 结构；
- SSE 流式响应不套普通响应包装；
- 请求和响应 DTO 使用 Java `record`；
- Controller 不返回数据库模型；
- 时间使用 ISO 8601；
- AI 输出除反序列化外还必须通过业务规则校验；
- 错误响应包含稳定错误码、用户可读信息、请求 ID 和时间。

## Gateway 边界

### ModelGateway

负责模型请求、普通或流式响应、超时和外部错误转换。它不检索资料、不组装业务工作流、不保存业务实体，也不开启数据库事务。

### RetrievalGateway

负责向独立检索服务发送索引和检索请求。业务模块不能依赖 C++ 内部索引结构、端口管理或进程生命周期。

协议端点、错误映射、队列和取消边界见 [AI 服务协议（ARCH-004）](AI服务协议-ARCH-004.md)。

### ModelRunService

由业务工作流调用，保存模型名称、任务类型、参数摘要、耗时、结束原因和成功状态，不保存完整提示词、资料全文或密钥。

## 数据库访问边界

`DB-001` 只暴露 Spring JDBC 的 `NamedParameterJdbcTemplate` 与模块 Repository 契约。`PostgreSqlJdbcConfig` 仅在 `STUDYPILOT_DB_URL`、用户名和密码均由环境提供时创建连接池；未配置数据库时，接口和 Gateway 契约测试仍可运行。

- Repository 使用参数化 SQL，Controller 不能直接访问 Repository；
- 所有业务表在 `studypilot` Schema，项目 ID 是隔离条件；
- 删除策略在 DDL 中显式表达：项目删除级联清理项目数据，问答引用保留资料名称、页码和原文快照；
- SQL 文件顺序、表关系和真实 PostgreSQL 验证见 [数据库演进记录](数据库演进记录.md)。

## 前端契约边界

目标约定来自 [前端框架设计](../../frontend/前端框架设计.md)：

- 具体请求只出现在模块 API；
- 组件、页面和 Store 不拼接接口路径；
- 外部响应先通过运行时 Schema，再由 mapper 转为内部模型；
- 外部 DTO 不直接进入组件和 Store；
- 普通 HTTP 请求使用统一 Axios 实例；
- 协议适配器只处理传输，不包含业务规则；
- 跨模块只能使用对方 `index.ts` 暴露的公共能力。

## PROD-002：真题分析与模拟卷

- **生产者**：`ExamController`；**消费者**：`frontend/modules/exam`。
- **请求与响应**：`POST /api/v1/exams/past-papers/{documentId}/analysis?projectId` 返回识别、归一与待复核题数；`GET /knowledge-points` 返回项目级频次；`POST /generate` 返回试卷 ID；`GET /{examId}` 返回该项目内试卷及题目。
- **错误行为**：资料不存在、类型不是已就绪真题或试卷不属于项目时使用稳定业务错误；模型 JSON、题型、数量、答案或资料来源无效时返回 `MODEL_OUTPUT_INVALID`，不写入试卷。
- **兼容性**：首次提供目标接口，无旧 API 迁移。
- **契约测试**：`ExamControllerTest`、`MockExamGenerationServiceTest`、`MockExamWorkflowEndToEndTest`。
