# StudyPilot 关键记录

本目录保存跨模块、跨会话必须长期保留的设计事实。Harness 负责工作状态，本目录负责解释“系统为什么这样设计、哪些约束不能被后续实现破坏”。

## 当前阶段

- 已完成：Harness、四项架构任务、PostgreSQL 数据库、三个产品模块和 `VERIFY-001` 系统级验证，状态均为 `verified`。
- 最终文档与交付一致性审计已完成；当前没有待执行的 Harness 任务。
- 当前运行架构为 Vue、Spring Boot、PostgreSQL、C++ 检索服务和 llama.cpp；课程版实现仅在归档分支保留。

## 记录规则

- 影响多个模块、数据边界、公共接口或迁移方式的决定必须建立 ADR。
- ADR 包含状态、背景、决定、备选方案、影响、验证和回退方式。
- 数据库变更同时记录 DDL、迁移、回退、数据兼容和验证环境。
- 接口变更同时更新生产者、消费者、示例和兼容性说明。
- 旧代码复用必须记录行为基线和验证证据，不把“文件复制成功”当成复用完成。
- 任务进度只写入 Harness；本目录不记录聊天式流水账。
- 不写入数据库密码、项目密钥、真实连接地址、模型密钥或个人资料全文。
