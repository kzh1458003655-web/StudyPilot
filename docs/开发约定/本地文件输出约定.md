# 本地文件输出约定

为了让课程设计资料、测试证据和应用运行数据集中在同一位置，StudyPilot 约定将**非版本控制的生成文件**默认写入 `D:\大四课程设计`。

| 文件类别 | 默认目录 | 说明 |
| --- | --- | --- |
| 用户上传的课程 PDF | `D:\大四课程设计\StudyPilot-runtime\uploads` | 后端可用 `STUDYPILOT_STORAGE_ROOT` 覆盖，用于其他电脑盘符不同的情况。 |
| 测试截图、接口响应和演示材料 | `D:\大四课程设计\StudyPilot-output` | 运行测试时产生的可查看证据放在此处。 |
| C++ 检索索引 | `D:\大四课程设计\StudyPilot-runtime\ai-index` | 由目标启动脚本使用，资料重建后可重新生成。 |
| 临时文件 | `D:\大四课程设计\tmp` | 可随时清理。 |

源代码和 Git 元数据继续保留在仓库工作副本中，避免移动工作副本导致分支、远端地址和组员协作失效。Maven 的 `target`、前端构建缓存等属于工具产生的可再生文件，仍由各工具在工作副本内管理，且不会提交到 Git。`start-target.ps1`、`stop-target.ps1`、`verify-target.ps1` 产生的日志、进程记录和验证摘要都默认使用上述 D 盘输出目录。

组员首次启动前可执行：

```powershell
New-Item -ItemType Directory -Force `
  D:\大四课程设计\StudyPilot-runtime\uploads, `
  D:\大四课程设计\StudyPilot-output | Out-Null
```
